# Mobile (Ogrenci & Veli)

Expo + React Navigation.

## Calistirma

```bash
cd mobile
npm install
npm run dev
```

Telefonda Expo Go ile QR okut veya `a` / `i` ile emulator.

## Mock / API

`mobile/.env` (ornek: `.env.example`):

- `EXPO_PUBLIC_USE_MOCK_API=true`
- `EXPO_PUBLIC_API_BASE_URL=http://localhost:4000/api`
